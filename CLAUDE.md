# ysorapalli.com (design C, "reads like a book")

Start with `CONTEXT.md` (project history, decisions, status), then `README.md`.
Design source of truth: `design-reference/` (canvas prototypes + DESIGN_HANDOFF.md). Copy lives in `content/site.ts`.

Rules from the owner:
- No em dashes in site copy unless she asks for them.
- No cursive or handwriting fonts.
- Keep copy plain and human; don't invent claims, numbers, quotes or posts.
- Planning and decision making are interests, not completed work.
- Light and dark mode must both pass contrast checks, and the toggle must work.
- Run `npm run check` before calling anything done.
